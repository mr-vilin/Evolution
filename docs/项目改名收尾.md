只有确认历史聊天不再依赖旧路径、旧进程已退出后，才可在独立 PowerShell 中移除此链接。以下操作明确检查链接类型和目标，并使用非递归删除，只移除链接：

```powershell
$legacyPath = 'D:\WorkBench\AI Projects\OrganizationalStructure'
$projectPath = 'D:\WorkBench\AI Projects\Evolution'
$legacyItem = Get-Item -LiteralPath $legacyPath -Force
if ($legacyItem.LinkType -ne 'Junction' -or
    [IO.Path]::GetFullPath([string]@($legacyItem.Target)[0]) -ne $projectPath) {
    throw '旧路径不是预期的兼容链接，停止操作。'
}
[IO.Directory]::Delete($legacyPath, $false)
Get-Item -LiteralPath (Join-Path $projectPath 'AGENTS.md')
```

若移除链接后发现遗漏的旧工具或聊天，可以恢复入口，不需要复制项目：

```powershell
New-Item -ItemType Junction -Path 'D:\WorkBench\AI Projects\OrganizationalStructure' -Target 'D:\WorkBench\AI Projects\Evolution'
```
