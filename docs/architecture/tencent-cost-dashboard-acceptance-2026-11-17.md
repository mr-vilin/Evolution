# T05 多月份费用看板与全量导出

对应 Issue #20。入口为「业务管理 → 腾讯云费用看板」；接口为账号下的 `cost-dashboard` 与 `cost-export`，查询参数 `start_month`、`end_month`（包含末月）和 `currency`（默认 CNY）。单次最多 120 个月，起点不早于 1970-01，不接受未来账月或额外参数。

## 读取口径

本地当前费用是唯一来源，浏览页面不调用腾讯云。查询和导出共用 `backend/app/tencent/cost_dashboard.py` 的 `read_dashboard` 边界，由调用方持有同一个 MySQL REPEATABLE READ 事务，读取账号、期间、全部产品与最近任务。总计保留 Decimal 精度并返回八位小数字符串；币种严格过滤，不跨币种相加。前端 BigInt 只缩放图形坐标，不计算业务金额。

完整且有效零费用显示 0；未同步、未到期和失败缺口保留空金额。已映射产品在完整月源端缺行显示 0；未映射或同名歧义以期间内行身份区分，其他月份显示 -，不按名称跨月错误合并。已采集金额允许展示保留旧值；完整范围总额只有所有月份均为当前有效完整结果时提供。月份逐项说明失败、更新中、过期与最近成功时间。

环比同比额外读取对照月；仅完整覆盖、当前世代、最近采集成功、口径一致且分母非零时计算，其他情况返回空值和原因。前端时间明确按 Asia/Shanghai 展示。

CSV 带 UTF-8 BOM，包含全部产品，不受表格搜索或分页限制。缺月有空金额状态行；无产品的有效零月也保留状态和 0。文本公式前缀中和，服务端格式化的负费用保留负号。下载失败或初始化/身份失效不能保存成费用文件。

## 权限与审计

两个端点分别使用 `tencent.cost.read`、`tencent.cost.export`，执行管理员会话、初始化与有限动作校验；机器身份不能替代管理员。账号停用后仍可查看历史。响应 no-store，入站审计保存独立动作、实际请求 ID 和服务端确认的 UIN，不记录费用正文或凭据。

## 验证及边界

已在登记的本机端口 13306、隔离库 `tencent_t05_test` 上验证 MySQL 8.4.11、utf8mb4 / utf8mb4_general_ci、UTC 会话和 REPEATABLE READ。仅 SDK 原始出站响应替换为固定样本，查询业务与 worker 发布真实运行。

- 9 条 HTTP / MySQL 回归：多月求和、缺月、有效零、同名歧义、失败旧值、12 产品全量导出、环比同比、币种与账号过滤、访问门槛和可信审计。并发屏障让真实 worker 在查询期间完成整月替换，确认同一响应总计和全部产品保持旧快照，下一次查询读取新结果。
- 前端 3 条测试：精确金额、缺口、有效零和不可比原因，全量搜索与刷新保留条件，失败隐藏旧数据，受保护 CSV 下载和初始化失效。
- 前端类型检查、Ant Design CLI lint 与生产构建按最终工作树执行，结果见交付报告。

本票先支持已手动采集的完整月份。T07 应在同一个 `read_dashboard` 边界引入自然月内互不重叠的日或整月结果，不复制月聚合费用；扩展查询、比较和 CSV 时需保留本票一致性与缺口测试，并增加月/日不重复金额回归。没有提前新增日表或虚构日字段。
