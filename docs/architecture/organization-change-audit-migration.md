# 组织变更记录审计迁移清单

组织变更记录仅展示飞书任务及订阅事件产生的员工、部门业务变更。历史通用审计表继续保留所有审计事实，原有通用查询接口可读取这些数据。以下六类已从组织变更页面移除，后续各模块承接查询能力。

| 原对象标识 | 中文名称 | 已有记录入口 | 后续迁移目标 | 当前状态 |
| --- | --- | --- | --- | --- |
| api_client | API 客户端 | API 客户端创建、密钥轮换、撤销 | API 管理审计 | 待迁移 |
| admin_allowlist | 管理员白名单 | 管理员添加、移除及恢复授权 | 权限管理审计 | 待迁移 |
| event | 飞书事件 | 失败事件重新入队 | 组织同步的事件处理历史 | 待迁移 |
| security | 登录安全 | 登录拒绝、员工失效后的会话撤销 | 安全审计 | 待迁移 |
| settings | 系统配置 | 同步计划、事件监控、覆盖验收 | 配置中心 | 待迁移 |
| dataset | 数据集恢复 | 数据库恢复工具的状态变更 | 系统审计 | 待迁移 |

迁移时核对各类型历史记录的来源、对象标识、执行人、变更前后数据及时间，沿用现有审计留存和访问权限。各目标模块实际承接后再更新状态。历史事件重新入队审计与本次新增的“飞书订阅事件”组织变更来源分别保留其含义。

另外，门店标记、部门本地排序、同步任务执行状态、系统初始化流程状态及腾讯云相关审计也不属于此页面的业务对象范围，继续由各自记录入口负责。
