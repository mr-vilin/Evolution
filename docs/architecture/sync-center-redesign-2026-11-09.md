# 同步中心调整与分批提交

## 用户确认的规则

2026-11-09：类型采用“初始化任务、全量同步任务、局部同步任务、全量校准任务”；另外展示触发机制及执行人，系统自动任务显示“系统”。用户选择“每批对象同步后立即入库，允许看到部分完成的数据”。

## 界面与含义

- 初始化只展示完成日期，来源为已完成初始化流程或历史成功初始化任务，不使用最近全量日期代替。缺少历史证据显示“暂无历史日期”。
- 通讯录覆盖表示全员及无部门成员的读取范围是否有有效证明。`unknown` 展示“待核验”，不等于同步失败。授权范围变化、覆盖证明缺失或不适用于本轮采集均可能导致待核验。
- 飞书事件连接依据最近重连或收到事件的证据，90 秒内显示“近期连接正常”，过期显示“暂无近期连接证据”，不能据此断言断线。检查监听进程、飞书事件订阅，以及真实通讯录变更事件的接收和处理；全量同步成功只能证明读取接口可用，不能证明事件链路。此轮未触发真实通讯录变更。
- 原“失败事件”是飞书成员／部门新增、修改、删除以及授权范围更新推送的处理失败，与同步任务分开。同步中心移除事件面板、失败事件计数及连接摘要；事件接口与重试能力继续保留。
- 列表不显示随机内部任务 ID，加入触发机制、执行人、创建时间；类型、阶段、状态在服务端筛选后再取最近 200 条。提供后端游标分页，当前界面明确展示范围。
- 状态采用 Ant Design 6 自定义颜色的 `Tag variant="outlined"`。进度同时展示采集和已入库计数，总量未发现前不编造百分比；总量已知时展示比例，任务最终完成前最多显示 99%。
- 详情路径 `/sync/jobs/:id`，兼容旧 `/sync?job=...` 链接。对象下拉默认成员，可切换部门；对象结果区分新增、更新、无变化、失败，展开可查看关联日志及具体字段前后值。成员结果合并成员本身及其部门关系变更，不将仅关系变更误判为无变化。

## 类型、触发机制与阶段

| 内部类型 | 显示名称 |
| --- | --- |
| `initialize` | 初始化任务 |
| `full` | 全量同步任务 |
| `subtree` | 局部同步任务 |
| `reconcile` | 全量校准任务 |

触发机制包括手动、每日定时、系统启动、连接恢复、覆盖范围重新确认、智能体调用、流水线调用和 API 调用；管理员重试显示“手动重试”，保留底层原始触发来源。人工姓名从现有身份映射和成员资料解析，无法关联姓名时保留请求方标识，不伪造姓名。缺少历史来源的任务显示“其他触发”。

普通任务有 7 个正常展示步骤：等待执行、读取权限范围、采集部门、采集成员、采集完成、汇总入库、执行完成。初始化另外有“校验数据”。异常／控制阶段包括等待初始化、采集失败、执行中断、已被替代；这些不是所有任务都会经历的顺序步骤。

## 事务与恢复

- 仅普通 `full`、`subtree`、`reconcile` 使用批次回调；初始化保持既有完整校验和首次发布门禁，事件保留单事件事务。
- 每累计 50 个尚未提交的已读取对象提交一个短事务；小于 50 的尾批在本轮采集完成时提交。成员与其部门关系在同一事务处理，未解析引用继续隔离为待核验，不生成悬空外键。
- 每批校验 worker 和 job 租约，按 `WorkerLease → DatasetState → SyncJob` 顺序加锁，更新投影及有内容变更的数据版本；只读客户端继续通过 epoch/version 检测跨批次变化并重读。
- 批次提交不把任务置为成功，不结束操作回执，不提前更新最近全量完成日期，不写入会被误认为完整检查点的 staging。
- 完整候选采集完成后保存完整 staging，最后执行范围核对及结果收束。先前批次的审计与变更链接在最终无变化处理后仍保留。
- 中途失败只回滚正在提交的批次，已提交对象仍可见。重试重新采集或使用已有完整 staging，不会把某一部分批次误认为完整候选；重复对象按现有 upsert 规则处理。
- 采集进度独立保存并附时间，查询只采用本次开始之后的快照，防止旧尝试的进度冒充重试结果。
- 这改变普通同步原先“整轮原子发布”的语义。回退镜像只恢复后续执行方式，不撤销已提交业务批次；需要撤销业务数据时应另行授权并按备份恢复流程处理。

## 环境与验证边界

本地实测 MySQL 8.4.11、InnoDB、`utf8mb4_general_ci`，稳定 ID 使用 `utf8mb4_bin`，连接会话为 utf8mb4 / utf8mb4_general_ci、UTC、REPEATABLE READ；迁移头 `0013_employee_profile`。本轮仅改查询与提交代码，无结构变更，无业务库迁移或手动发起全量同步。
