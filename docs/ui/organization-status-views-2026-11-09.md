# 组织架构状态数标与面板查看

## 有效行为

- 顶部总部门数、总人数、未激活、未加入、已离职固定为全组织汇总，切换部门不再改变。统计与搜索、下拉筛选、分页独立；未知状态不推断为未激活或已离职。
- 未激活、未加入、已离职标题旁增加眼睛查看按钮，悬停提示「查看全组织××人员」；选中后整格采用绿色背景、描边和数值。再次悬停提示「恢复本组织默认列表」，再次点击清空人员搜索和筛选，恢复本组织默认列表；零人数也可查看。
- 查看时列表标题变为对应状态，人数来自该状态查询；两个下拉框禁用，搜索仍按姓名、完整手机号或 user_id 在当前状态内查询。切换其他面板状态清空搜索；选择部门退出状态查看，恢复普通部门浏览。
- 状态查看使用与全组织面板一致的人员事实，包含失效和历史人员、无有效部门关系的人员，按人员去重；不套用普通浏览的超过 20 人仅展示直属成员限制。列表每页 20 人，向下滚动续载，并保留加载按钮作为补充入口。
- 普通部门浏览的账号状态下拉除「全部账号状态」外，每项右侧展示 Badge：已激活 `#52C41A`、未激活 `#FAAD14`、已暂停 `#FF4D4F`、未加入及状态未知 `#F5F5F5`；浅灰底使用深色数字。零值显示 0，超过 99 显示实际数量。数标仅展示在选项列表；收起时保持原有选项文字。未激活以用户最新确认的橙色为准，不使用蓝色。
- 数标按当前部门和「展示成员」范围汇总，不受人员搜索词、已选账号状态或当前分页影响。已激活、未激活、已暂停、未加入、状态未知是独立事实，可能重叠，不能相加当作总人数。普通搜索仍覆盖当前部门及下级，数标保持下拉框所选范围。
- 「状态未知」是本系统对 `is_activated`、`is_frozen`、`is_unjoin`、`is_resigned`、`is_exited` 中任意字段缺省的兜底筛选，不是独立的飞书账号状态。2026-11-09 同日颜色调整前只读核验：本地 44 位当前人员上述字段均非空，未知筛选人数为 0；保留该选项处理未来缺失资料。

## 技术边界

- 现有管理员 GET `/admin/api/organization/employees` 新增 `view_status=none|unactivated|unjoin|resigned`，返回 `meta.account_status_counts`；保留管理员认证、初始化门禁、数据世代／版本检查及游标与筛选条件绑定。
- 面板查看请求使用根部门 `0`；普通账号状态与面板查看分别处理，面板查看中不叠加已禁用的账号状态下拉条件。
- MySQL 8.4.11；本地连接实测 `utf8mb4`／`utf8mb4_general_ci`，稳定 ID 为 `utf8mb4_bin`；相关状态列均为可空 `tinyint(1)`。只调整查询，无模型或数据库迁移，不触发同步或初始化。
