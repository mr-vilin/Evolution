# 组织架构人员列表与详情抽屉

## 已确认需求

- 列顺序：头像＋姓名＋复制 user_id、账号状态、手机号码、直属上级、部门、人员类型、职务、门店属性、权限角色、操作。
- 姓名列固定左侧，操作列固定右侧，仅提供“查看详情”；点击姓名也打开右侧抽屉。小屏缩小两侧列宽，仍保持固定。
- 复制使用飞书 `user_id`，不以内部记录 ID 替代；缺失禁用，失败提示手动复制。
- 账号状态使用 Ant Design 6.6.4 `Tag variant="solid"` 与主题语义色，保留多状态展示和未知状态。
- 部门显示前三个普通标签，末尾 `+N` 也使用相同标签；无删除按钮。点击、聚焦或悬停可查看全部部门路径。
- 列表和详情的直属上级位于部门字段前，均用头像＋姓名展示；未同步头像使用默认头像。
- 虚拟根展示“本组织”；下级人员部门路径省略开头虚拟“组织”，不删除路径中间的同名真实部门。

## 抽屉

顶部依次展示头像、姓名、账号状态；下一行主部门完整路径，随后分隔线。

详情顺序：用户ID、手机号码、邮箱、直属上级、部门、人员类型、入职日期、职务、门店属性、权限角色。人员类型使用实心标签；所属部门默认五个，超过五个显示“查看更多”，展开后可收起。部门标签悬停或聚焦可查看完整路径。

关闭抽屉保留列表筛选、选中部门及滚动位置。切换人员重置折叠状态，旧请求被取消，失败提供重试；不显示上一个人的资料。

头像与入职时间经采集、持久化和读取接口提供。迁移及执行边界见 [0013 迁移手册](../../deploy/migrations/0013-employee-profile.md)。

- 前端 11 项测试通过；生产构建（含类型检查）、版本检查和修改组件的 Ant Design lint 通过。
- Chromium 在 1440×1000 与 390×844 的构建预览中验证了左右固定列、手机列宽不重叠、复制真实 user_id、部门标签/折叠/完整路径、抽屉开关以及关闭后保留横向滚动；未捕获页面运行异常。
