# 项目设计规范

本规范适用于 OrganizationalStructure 所有面向用户的页面设计、开发与验收。以下规则于 2026-10-26 由用户确认；历史原型或现有页面与本规范不一致时，以本规范为准。

## 表格规范页面与列表约定

「UI标准 / 表格规范」对应 `/ui-standards/table`，与设计标准同级。页面按高度与滚动、列布局、单元格与操作、受控筛选与排序、无新增类、可新增类、应该／不要七章组织，共展示高度布局、无新增、可新增三张交互表格；交互仅使用本地演示数据，不调用业务查询或写入接口。完整计算口径、状态变化表和验收要求见 [表格规范页面方案](table-standards-plan-2026-11-13.md)。

- 白底容器包括标题、工具栏、表头、表体、横向滚动条与分页。以 `H = V - T - Gt - Gb` 计算可用一屏容量，`A = V - Gb - Y` 计算初始首屏空间；`A >= 0.6H` 时容纳于首屏，数据行内部滚动；不足 60% 时按 H 布局，整块容器滚动到顶栏下方留白后吸顶，并保留布局占位。尺寸、缩放、侧栏和工具栏变化后重新测量，滚动时不切换模式；少量记录自然收缩，不以记录数量判定模式。
- 名称等识别列固定左侧，业务字段居中，时间集中放在操作列之前，操作固定右侧；确有批量操作时才增加勾选列。无关技术 ID 不独立展示，可从名称旁复制真实 ID，复制失败提供手动方式；长文本悬停或键盘聚焦可完整查看。所有列具有稳定唯一的 key，记录另设 rowKey。
- 时间按页面时区以 `YYYY-MM-DD HH:mm:ss` 展示，时间列均支持排序；缺失值、空字符串、纯空白显示 `-`，有效零值保留。人员列使用圆形头像加姓名，两者间距为 1 个 unit（4px）；无头像时中文取首字，英文取首单词，首单词超过 5 个字母则取前 3 个字母。表格状态列明确使用带中文文案的语义 Tag；未开始、无效和未知保留各自真实文案，使用中性 Tag。页面级关键反馈继续使用 Badge 或 Alert。进度使用条形和百分比，没有依据时显示 `-`。
- 行操作使用有中文 Tooltip 和可访问名称的图标按钮；不超过 3 项全部显示，超过时为「2 个高频图标 + 更多操作」，其余操作在带图标和中文名称的菜单中；删除使用危险样式并确认。
- 无新增类左侧最多 4 个主要业务筛选条件，筛选框内默认显示“全部状态”等字段文案，刷新紧随其后，右侧搜索；第 5 项及之后放入各自表头，不增加独立“更多筛选”，同一字段不重复入口。可新增类左侧搜索，右侧按新增、刷新排列，附加筛选放在表头。示例搜索使用标准搜索框，明确提示搜索名称或负责人。
- 搜索、筛选、单列排序和分页由页面统一受控管理。各筛选列持续传入 filteredValue，数字及时间排序列持续传入 sortOrder，空状态为 null。数字按真实数值比较，时间按统一格式的先后比较；升降序均将缺失值置底，同值保持基准顺序。切换排序列清空上一列方向。先处理完整数据源的搜索与筛选，再排序，最后分页；远程分页接入另行核实服务端能力。
- 搜索、筛选、排序变化返回第 1 页；刷新保留全部查询和有效页码，结果缩减时校正页码。演示不批量整改既有业务列表，也不表示业务列表已验收或部署。

## 配置与录入使用结构化表单

- 除非需求明确要求用户直接编辑 JSON，否则不得让用户通过填写或粘贴 JSON 完成配置，也不得自行提供“高级模式”“源码模式”等 JSON 编辑入口。
- 选项列表、字段映射、键值对等多条目配置，一律采用手动加行的形式，支持新增、逐行编辑和删除。
- 每行按业务含义拆分为独立字段，使用明确的中文标签；根据字段类型使用输入框、选择器等控件，不要求用户理解大括号、引号、逗号等 JSON 语法。
- 系统负责将表单数据转换为接口需要的 JSON，并将已保存的数据还原为可编辑的表单行。接口或数据库使用 JSON，不构成界面使用 JSON 输入框的理由。
- 必填、重复标识及其他已确认的业务约束在对应行和字段旁提示；校验或保存失败时保留用户已填写的内容，不让用户依靠 JSON 解析错误排查输入。
- 只有对应需求明确提出直接编辑 JSON 时才可例外，并在需求或设计文档中记录适用页面、用途和确认依据；开发便利、管理员身份或配置复杂度均不能自行构成例外。

## 设计与验收检查

- 用户能否不编写 JSON 就完成配置，包括读取已有配置、增加条目、修改条目、删除条目和保存？
- 每一行的字段含义是否清晰，校验提示是否能定位到具体行和字段，失败后是否保留输入？
- 如存在 JSON 编辑入口，是否有明确需求及确认依据，而非开发人员自行决定？

本规范约束用户交互方式，不改变接口的数据格式、存储结构或已确认的业务规则。

## 设计标准页面与动态颜色

工作台菜单「UI标准 / 设计标准」对应 `/ui-standards/design`，移植用户于 2026-11-10 指定的设计准则页面，展示价值观卡片、色彩、字体、布局、圆角、间距和 14 个组件条目，随后展示阴影、动画与收尾规则。字体和组件的代码切换、色值复制与弹窗均可交互。

设计说明不再作为独立章节展示：价值观保留在页首；颜色与排版融入对应模块，不附整段原文。「布局」独立放在「圆角与形状」前，包含三层表面示意、适用位置、使用时机、边框与阴影的选择及 4px 网格用法，模块内不附原文折叠说明。形状的用途与示例合并到「圆角与形状」，原 `#note-5` 锚点指向合并后的说明；组件说明合并到「组件样式」，原 `#note-6` 锚点指向其介绍区。「高度与深度」12 段中的前 7 段提炼到「阴影」，后 5 段提炼到「动画」；两个独立、完整宽度的模块位于组件样式之后，分别使用 `#shadows`、`#motion`，原 `#note-4` 锚点指向阴影介绍区。原始准则文件与完整附件不删改。

「圆角与形状」与「间距应用」是两个平级、完整宽度的模块，位于布局之后、组件样式之前，顶部导航与后续章节编号同步调整。圆角模块保留原 `#geometry` 锚点，间距使用 `#spacing`。

- 圆角按用途同时展示数值、适用场景和实例，并按 0px、2px、4px、6px、8px、full 递增排列：表格内部或分段控件相邻边缘 0px，复选框方框 2px，分类标签与 Tooltip / Popover 本体 4px，默认控件及多选器已选项 6px，内容表面 8px，圆形头像、徽标及状态点使用 full。表格外部容器仍可保留所属类别的圆角。
- 部门信息卡片组合示例标出外框 8px、内部控件 6px、标签 4px、圆形头像与状态点；头像与姓名间隔 1 个 unit（4px），同样适用于表格中的人员列。示例展示 8px 卡片内放置 16px 按钮的不推荐搭配。同类控件保持一致，不同类别按用途组合，全圆角不用于普通按钮或标签。
- 圆角实例通过局部主题使用与标注一致的实际组件圆角：Checkbox 方框 2px；Select 多选已选项（`ant-select-content-item` 内承载选中内容的项）6px，支持选择和移除成员。4px 示例仅展示分类标签与常显的 Tooltip / Popover 浮层，保留浮层底部的三角箭头，不展示触发按钮与操作提示。Tooltip 用于简短文字解释，Popover 可含标题与更多内容；浮层由组件定位。full 示例依次展示头像及右侧姓名「林晓」、多个成员头像叠加、同步状态。局部圆角配置继承系统颜色，不影响其他业务页面。
- 七档原始圆角刻度完整保留并递增排列；2px 对应复选框案例，16px 仍标注为当前规范未指定常规应用场景，不补造用途。
- 「间距应用」参照圆角模块，同时展示数值、适用场景与实际测量案例：4px（1 个 unit）用于头像与姓名、标题与人数等紧密附属信息，8px 用于同行操作组，16px 用于并列统计卡或摘要卡的栅格、普通内容间隔及紧凑小卡片内边距，24px 用于章节、桌面内容区及常规卡片内边距，32px 用于较大独立内容区域之间的留白。具体场景是项目应用约定，不将原先自行补充的 12px 卡片间距作为 Ant Design 固定标准。
- 间距沿用原有 4px 浅色格尺与主题色条形，案例底板使用同尺度网格；浅主题色标出真实空白，横向及纵向尺寸线放在间隙外侧，不撑大被测量的距离。组合示例将 4 / 8 / 16 / 24 / 32px 放回组织概览与成员查询界面；查询和重置仅操作本地示例成员，不调用业务接口。
- 删除底部重复的完整间距刻度、说明与条形列表；`unit / xs` 合并展示在 4px 案例中。`control-height: 32px` 的实际按钮与高度标注合并到 32px 案例，区分控件自身高度与元素间距。原始准则与参考附件保持完整。

常规界面使用以下八种职责色；HEX 色值后提供同色线条吸管图标，悬停时变为当前主题色，点击打开取色器。三个图标按钮均无背景、边框、悬停过渡或原生提示框，保留键盘焦点提示；勾选固定为 `#52C41A`，重置固定为 `#FF4D4F`。移除色卡下独立的 HEX 输入框。选色后实时预览全局效果，并显示勾选、重置图标：勾选只保存当前色卡，重置恢复最近保存的该职责颜色，不影响其他待确认色卡：

| 职责 | 默认值 | 应用范围 |
| --- | --- | --- |
| 主题色 | `#1677FF` | 主操作、链接、选中导航和焦点；悬停、按下、浅背景由 Ant Design 算法派生 |
| 辅助色 | `#13C2C2` | 次要图形、辅助内容与系列 |
| 点睛色 | `#FA8C16` | 少量重点内容与图形 |
| 背景色 | `#F5F5F5` | 工作台、初始化与登录页画布 |
| 内容白 | `#FFFFFF` | 侧栏、顶栏、卡片、表格、输入框及弹窗表面 |
| 正文灰 | `#1F1F1F` | 标题、正文与主要数据 |
| 说明灰 | `#595959` | 说明、时间与单位；禁用文字按该色和内容表面混合 |
| 线条灰 | `#F0F0F0` | 分隔线和边界；控件边框按该色与正文色派生 |

根级 `ThemeProvider` 通过 Ant Design 6 的 `ConfigProvider.theme` 和 `defaultAlgorithm` 管理主题；ProLayout 读取同一配置，自定义 CSS 与 SVG 图形使用根级颜色变量。辅助色、点睛色属于项目扩展，不虚构 Ant Design 全局 token。反馈通过现有 `App` 上下文继承主题。

成功、告警、错误保留独立语义色，提示色跟随主题色；设计规范中的 12 种扩展色作为固定分类参考展示。品牌 Logo 和历史 UI 原型图片保留素材自身颜色。

勾选后颜色写入当前浏览器、当前站点的 `organization.design-colors.v1`，刷新后保留，并同步到同源标签页；未确认的预览只在当前页面会话生效，刷新后丢弃，其他标签页的保存不会覆盖本页待确认草稿。「恢复默认颜色」同时恢复八色并持久保存。不是数据库或服务端全员配置，不同步到其他设备，也不修改全局 Skill 或项目文件。存储失败时保留草稿与确认操作，允许重试或重置，不将失败值当作已保存。

价值观卡片移出或失焦后，背景用 0.5 秒恢复内容表面色，中文文字在移出后 0.3 秒开始用 0.5 秒淡入，即比背景变白完成提前 0.2 秒；减少动态效果设置下取消过渡。

顶部四张价值观卡片的中文标题左侧分别使用 Ant Design 图标：自然为 `SunOutlined`，确定为 `CheckOutlined`，有意义为 `SmileOutlined`，成长为 `LineChartOutlined`。图标与标题同为 16px，垂直居中、间隔 8px，使用当前主题色，不加外框。图标随中文标题一起隐藏和淡入。

## 组件样式的说明与交互

- 以主要按钮、默认按钮、输入框、选择器、卡片、弹窗、菜单、页签、表格、分类标签、提示反馈、状态点、文字提示、下拉菜单共 14 个条目组织内容。按钮的正常／悬停／按下、输入框的默认／聚焦在同一个真实控件上体验；四种 Alert 在同一条目中对照，分类标签不再拆成默认与蓝色两个样例。
- 桌面每行左侧展示用途、尺寸和使用限制，右侧展示真实组件；窄屏上下排列。普通控件 32px 高、6px 圆角；卡片和弹窗 8px，分类标签和 Tooltip 4px，状态点 6px。卡片四边 24px 内边距、内部 16px 间隔；弹窗主体上下 20px、左右 24px，使用次级阴影、主题遮罩并由框架居中。
- 输入框聚焦保持 1px 边框，用主色边框和框架焦点光晕增强反馈，避免改变控件尺寸；Ant Design 的 Input、Input.Search 和 Select 使用组件自身的聚焦样式，不再叠加页面通用的原生 input outline，以免出现框内又一圈蓝框。默认按钮使用当前内容表面色。选中菜单和活动页签保持 400 字重，分别通过主色浅背景和 2px 下划线突出；页签各状态不填充背景。表头 14px／600，正文 14px／400，默认无斑马纹，仅悬停当前行时高亮。
- 示例颜色按用途读取现有主题：主色、悬停、按下、选中浅背景由算法派生；内容表面、浮动表面、正文、说明、占位和边框分别读取对应职责。反色文字使用 `colorTextLightSolid`，Tooltip 背景使用 `colorBgSpotlight`，遮罩使用 `colorBgMask`，不再以默认 HEX 值统一替换，避免把白色文字误绑定到内容表面。
- 成功、告警、错误保持原语义色，信息随主题色；Alert 使用语义浅背景与图标、正常正文颜色。Badge 同时提供圆点与状态文字。分类 Tag 使用现有预设扩展色的 filled 浅色样式；表格状态列使用带中文文字的语义 Tag（见下文表格规范），页面级关键反馈使用 Alert 或 Badge。Tooltip、Select、Dropdown 和 Modal 均由框架管理浮层定位与交互。
- 每行保留右上角 `</>`。切换仅替换右侧实例区域，左侧说明始终可见；代码包含基础与相关交互状态，标明主题令牌并显示当前解析值，随主题变化更新，自动换行并自然撑高，不增加内部滚动条。组件尺寸和主题覆盖局限于该模块，交互示例只操作本地示例内容。

## 阴影与动画的说明及案例

- 章节顺序为组件样式 06、阴影 07、动画 08、Do Or Not Do 09，顶部导航与布局模块中的引用保持一致。
- 两个模块沿用左侧说明、右侧真实案例的行式排版；窄屏上下排列。每行可通过 `</>` 仅切换右侧样例与代码，左侧用途和限制持续可见。代码展示当前主题解析值，自动换行、自然撑高，不设置内部滚动条；切换代码不清空本地示例状态。
- 阴影以扁平优先为原则，分别展示无阴影内容卡、轻型抬升批量操作条、标准菜单浮层、按需抬升的部门入口卡、四个方向的抽屉、真实页签溢出阴影、气泡卡片箭头。普通内容不附加装饰阴影，专用阴影由对应组件按方向、滚动位置与当前版本的绘制方式使用。卡片的键盘聚焦与悬停表达相同层级。
- 阴影组合案例使用本地成员列表，从更多菜单打开成员详情抽屉，说明列表、临时菜单和详情表面的前后关系；不访问或修改业务数据。
- 动画展示快速状态反馈、中速筛选折叠、慢速抽屉进出。100 / 200 / 300ms 是原文默认参考，展示与代码读取当前主题实际时长；真实组件保留框架自己的进入、退出和焦点管理，不用统一时长覆盖所有组件。
- 三档时长对照采用相同距离、相同缓动的一次单程，时长与标注一致；缓动对照采用相同距离、相同时长，展示当前版本可用的 `motionEaseInOut`、`motionEaseOut`、`motionEaseOutCirc`、`motionEaseOutBack`。用户点击播放或重播，不自动循环。原文的 `motionEaseIn` 在当前版本未作为独立令牌提供，默认回退选择为 `motionEaseInOut`，不改写原始附件。
- 开启系统「减少动态效果」后，本模块的真实组件关闭动画，状态仍可操作，对照轨道直接呈现终点；修改偏好时即时生效。局部主题仅约束这两个模块，颜色继承系统职责，原始准则和参考附件完整保留。

## 收尾规则与主题说明归属

## 常用文字用法

设计标准页的字体层级采用以下五类常用样式。每行保持左侧 CSS 类名、中间用实际文字说明作用与使用位置、右侧字号／行高、字重及当前色值的布局。

| CSS 类名 | 用途 | 字号／行高 | 字重 | 默认颜色 |
| --- | --- | --- | --- | --- |
| `page-title` | 页面顶部标题，如组织架构、同步中心 | 24px／32px | 600 | `#1F1F1F` |
| `section-title` | 卡片、抽屉与区域标题，如同步任务、成员详情 | 16px／24px | 600 | `#1F1F1F` |
| `body-text` | 姓名、部门、手机号码等业务数据，以及输入内容和普通控件文字 | 14px／22px | 400 | `#1F1F1F` |
| `secondary-text` | 页面说明、详情字段名称和需要读懂的表单帮助 | 14px／22px | 400 | `#595959` |
| `caption-text` | 人数、单位与非关键更新时间等附属信息 | 12px／20px | 400 | `#8C8C8C` |

- 表头沿用 14px 正文并加重至 600；日志提交时间等关键数据使用主要内容样式，不因内容是时间就自动弱化。
- 产品 UI 中只出现两种字重：400（正文、控件、菜单项、标签页标签）和 600（`fontWeightStrong`——标题、表头以及任何标题级排版）。
- 细体（100–300）、粗体（700+）和斜体不用于界面 chrome——它们会与系统追求的平静、确定基调相冲突。
- 斜体仅在长篇文档正文中可接受。选中/激活状态的视觉强调来自颜色和描边（边框、下划线），而不是字重。
- 占位与禁用属于控件状态，字号继承所在控件，不增加第六类常用样式。默认白底色统一为 `#BFBFBF`；三级文字为 `#8C8C8C`。两者分别按 `0.25 / 0.65`、`0.45 / 0.65` 将说明色与内容表面混合，保留自定义主题的联动。
- 链接与选中项使用主题色，成功、告警与失败使用对应语义色。
- 字体与组件的代码按钮保留原位置和切换操作；展开使用当前主色浅背景，代码自动换行、自然撑高，不设置代码区内部滚动条。
- 五类样式是设计标准展示与后续页面实施的依据；本次不批量调整现有业务页面的字号。原始准则和参考附件完整保留。
- “字体栈”与同区域的“使用规则”使用相同的字体、字号、字重、行高和颜色，不使用等宽代码字体。
