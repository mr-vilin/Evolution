## 当前工程事实

项目已经采用 Ant Design Pro 6.0.3 的工程约定，使用 Umi Max 4.7.23、Utoopack、Ant Design 6.6.4 与 ProComponents 3.1.14-2。本次沿用已确认的技术栈。

当前工作台使用混合布局、自定义顶栏和六个业务主菜单，人员详情为隐藏路由，初始化向导独立于工作台。此前迁移有意裁剪了官方演示业务，本次新增完整参考案例属于范围扩展。

源码核对依据为既有迁移固定的官方提交 `52506486ea134486937043c5fb677d89bbcd07f2` 的 [routes.ts](https://github.com/ant-design/ant-design-pro/blob/52506486ea134486937043c5fb677d89bbcd07f2/config/routes.ts)、[defaultSettings.ts](https://github.com/ant-design/ant-design-pro/blob/52506486ea134486937043c5fb677d89bbcd07f2/config/defaultSettings.ts) 与 [package.json](https://github.com/ant-design/ant-design-pro/blob/52506486ea134486937043c5fb677d89bbcd07f2/package.json)。其中包含欢迎、管理、Dashboard、表单、列表、详情、结果、异常、账户、登录注册和聊天示例；具体页面清单及行为仍需纳入后续确认。

现有认证只允许管理员登录；前端统一 AuthGate 与后端管理员白名单共同承担访问限制，没有另一个现成的普通用户角色。顶栏当前提供导航折叠、工作台标题、管理员身份和退出；同步状态位于同步中心，版本信息位于系统信息。

浏览器检查因工具无法可靠识别当前 URL 而终止，目前尚未取得预览站的视觉核验结果。上述页面类别来自官方固定版本源码，不构成在线预览视觉验收。

## 最终实施基线草案（Q7 待确认）

以下版式细化已确认的统一布局范围；最终确认后实施。

### 全局外壳与导航

- 沿用官方完整模板的布局结构和样式，使用项目既定版本，保留官方页面源码出处及必要许可。
- 品牌“组织服务”，默认浅色、蓝色主色、流式内容宽度、混合导航；保留现有固定顶栏和侧栏能力。
- 三个顶层区域为业务管理、系统管理、参考案例，侧栏按当前区域展开对应页面；案例内部沿用官方类别层次。
- 地址栏中的既有业务路径继续有效，组织架构为首页，人员详情归属组织架构；未知业务地址保持既有兜底行为，案例 404 页面有自己的演示入口。
- 统一面包屑、页面标题、说明、主操作区、内容卡片和间距，避免叠加重复的标题或面包屑。
- 顶栏沿用可用的管理员身份与退出，提供布局设置和指向系统信息、官方参考的帮助入口。现有真实功能直接复用；通知、搜索、个人资料等示例能力置于参考案例中演示。
- 布局设置用于调整当前浏览器的外观与布局，可恢复默认；不改变全局业务配置、其他管理员设置或权限。界面文案保持中文。

### 业务页面版式

| 页面 | 计划版式 | 重点保留的业务行为 |

| 同步中心 | 状态卡片、连接摘要、任务和事件列表、任务详情抽屉 | 状态筛选、全量更新、任务详情、失败重试；状态显示使用真实接口结果 |

初始化向导继续独立全屏，保留当前步骤、字段、校验和数据行为。共享样式调整应验证不会影响向导。

### 完整参考案例清单

完整保留案例的页面结构与有参考价值的交互，不用空白页、链接集合或一个通用占位页代替各类官方案例。

| 类别 | 页面 |
| --- | --- |
| 欢迎与管理 | 欢迎页、管理示例 |
| Dashboard | 分析页、监控页、工作台 |
| 表单 | 基础表单、分步表单、高级表单 |
| 列表 | 查询表格、标准列表、卡片列表；搜索列表的文章、项目、应用 |
| 详情 | 基础详情、高级详情 |
| 结果 | 成功页、失败页 |
| 异常 | 403、404、500 |
| 账户 | 个人中心、个人设置 |
| 用户页面 | 登录、注册、注册结果 |
| 聊天 | 聊天界面与模拟回复 |

- 示例页面统一使用 `/examples/` 路径空间及现有管理员认证门禁，明确标注“参考案例 / 演示数据”；登录、注册也只是认证后的案例。
- 演示增删改只影响当前案例会话，刷新可恢复初始样本；演示登录不创建真实会话，演示注册不创建账户，演示个人设置不修改管理员资料。
- 案例表单保留有意义的字段校验、分步状态与结果，列表保留查询、分页及对应的演示操作；图表使用本地演示数据。
- 聊天保留输入、回复和会话状态等参考交互，回复来自本地模拟，不发送用户文本到外部模型。
- 演示请求使用独立的本地适配层，不注册会拦截业务请求的全局假接口；不接入官方生产示例 API 或另一套 currentUser/login 身份机制。
- 页面需要的图表、样式等依赖按实际官方源码补充，与现有锁文件同步并验证兼容性；不借此升级既定框架或构建工具。参考案例按路由加载，业务首页不提前加载全部案例代码。

### 验收清单

1. 类型检查、现有相关前端测试、生产构建、受影响 Ant Design 组件检查及 `node scripts/versioning.mjs check` 通过。测试重点为业务行为、演示数据隔离和认证边界。
2. 按官方页面清单逐项检查案例可访问、异步资源可加载，关键表单/列表/步骤/聊天交互可操作；业务原路径刷新和直接访问有效。
3. 桌面 1440、平板 1024、手机 390 像素宽度检查导航、内容、表单、抽屉和表格；导航和操作可通过键盘使用，窄屏表格可局部横向滚动。
4. 未登录、无权限、初始化未完成和正常管理员状态的门禁符合现有流程；演示页面不绕过门禁。
5. 案例演示不会改变真实业务资料或触发真实登录、注册、同步和客户端管理动作；无官方示例 API/外部模型请求，真实业务仍访问既有接口。
6. 验证布局设置的改变与恢复、面包屑、菜单选中和人员详情归属；重新打开业务页及独立初始化页无样式回归。
7. 代码与检查通过后按标准发布工具部署本地 Docker，核实镜像、页面和异步静态资源。若迁移版本或运行状态阻断发布，停止该发布步骤并明确说明，不自行迁移或清理业务数据。
8. 最终报告分别列出已实现、已验证、未验证与环境阻塞；健康检查不替代浏览器业务验收，参考站视觉相似度须另有实际视觉检查证据。
