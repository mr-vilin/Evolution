# 腾讯云费用按期间保留当前值，余额仅实时查询

2026-11-17 用户确认：每个已成功采集的费用账期只保留当前一份完整产品结果，更正时事务覆盖；余额进入页面或手动刷新时查询，不建余额历史表。选择该边界可避免同时维护费用版本和余额采集链路，代价是无法从业务库查看旧费用金额或回放历史余额，因此失败须保留原期间结果，近期费用自动复核，更早费用支持手动重拉。执行追溯保留完整脱敏的实际输入及处理器提交回执，内部账单响应不复制为另一份费用历史；范围及答复见 [设计审查记录](../architecture/tencent-cloud-cost-design-review-2026-11-17.md)。
