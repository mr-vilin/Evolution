# ADR 0003：采用 SemVer 并重设开发基线

> 历史决策归档：保留开发基线和版本来源的事实依据，原项目版本规则已移除。版本决策只使用全局 `version-management-guidelines` Skill；项目实现入口见 [版本实现说明](../versioning.md)。


- 状态：历史归档，版本规则已由全局 Skill 替代
- 日期：2026-10-24
- 依据：用户确认采用 SemVer，且尚未正式上线，明确要求从 0.1.0 开始。
- 当时的替代范围：ADR 0001 的旧版本流程及手工同步页面方式。

## 决策

2026-10-24 从 `0.1.0` 建立开发基线，以根目录 `version.json` 为产品版本声明。旧 v1.0、v2.8.62、v2.8.63 及当时证据归档为历史开发记录，不属于新的发行序列。

当时用户确认系统尚未正式上线。产品版本、包版本、API 契约、数据库结构和业务数据版本分别管理。

版本声明随代码受 Git 管理，构建元信息随镜像保存。此次实现未以数据库作为软件版本来源，未新增版本表或执行迁移。

## 验收与限制

当时引入版本工具、相关测试、CI 与构建元信息；系统信息页显示前端构建和受保护的后端运行元信息。工具的现行能力见 [版本实现说明](../versioning.md)。历史验收不代表当前真实部署、数据库或飞书环境的验证结果。
