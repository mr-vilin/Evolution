# 完整参考案例

本目录对应用户于 2026-11-04 确认的 Q7 实施基线，共 27 个页面。路由、中文名称、分类及对应官方源码位置由 `frontend/config/examples.ts` 统一维护，Umi 为页面生成异步入口。

## 来源与许可

- Ant Design Pro **6.0.3**，固定提交 [`52506486ea134486937043c5fb677d89bbcd07f2`](https://github.com/ant-design/ant-design-pro/tree/52506486ea134486937043c5fb677d89bbcd07f2)。
- 对照其 `src/pages/` 目录的欢迎、管理、Dashboard、表单、列表、详情、结果、异常、账户、用户和聊天页面进行本地适配。
- 保留官方 MIT 许可：`frontend/public/licenses/ant-design-pro-MIT.txt`；每个页面的页脚链接到对应固定源码和许可。
- 欢迎页的速查内容摘编自该提交的 `docs/cheatsheet.zh-CN.md`。

## 隔离与生命周期

- 案例经过业务共用的 `Providers → AuthGate`，未初始化时只挂载全屏初始化向导。
- 不导入业务 HTTP 模块，不请求官方演示 API，不调用外部模型，不写入 Cookie 或身份存储；所有表单与列表数据存于页面 React 状态。
- 案例登录、注册、安全设置、绑定、验证码与转账只生成本地反馈。注册结果使用固定虚构账户，无资料写入 URL 或持久存储。
- 页面刷新恢复合成样本；布局偏好由独立版本化 localStorage 键保存，不能影响权限或业务设置。
- 聊天延迟回复在卸载、停止或重置时取消，防止旧回复进入新会话。

## 官方版适配边界

- 保留各案例的信息层次与主要区域。业务工作台采用组织服务品牌和中文帮助入口；案例增加显著的演示标识和源码页脚。
- Dashboard 使用本地 SVG 图表和合成区域分布，避免引入第二套图表运行时与远程地图；保持指标、趋势、排名、占比、预测及工作台区域。
- 外部头像、封面改用本地色块与文字头像；账户及聊天不加载真实身份或远程模型。
- 官方服务端增删改改为页面内状态更新；官方只展示按钮的部分页面补充可验证的本地操作反馈。
- 配置与录入使用中文结构化字段；高级表单成员行支持增删改、必填及重复工号校验，不提供 JSON 编辑入口。

验证时应逐页执行交互、深链接和刷新，结合生产产物的网络记录检查隔离，不能仅根据此清单或菜单数量认定验收通过。
